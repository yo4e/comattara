# こまったらドットコム

**困ったときに、助けてくれる場所へたどりつくためのサイトです。**

生活していると、「どうしたらいいのかわからない」と思うことがあります。

- お金がない
- 仕事がない
- 家賃が払えない
- 病気になった
- 家族のことで困っている
- 学校のことで困っている
- だれかに相談したい
- でも、どこへ行けばいいのかわからない

「こまったらドットコム」は、そんなときに使うためのサイトです。

むずかしい制度の名前を知らなくてもかまいません。
今、何に困っているのかを、ふつうの言葉で入力してください。

その内容にあわせて、役所、相談窓口、支援制度、医療機関、NPOなど、助けてくれる可能性のある場所を紹介します。

## めざすこと

このサイトがめざすのは、

**「助けてもらえる場所があるのに、知らないために助けてもらえない人」を減らすことです。**

制度を説明するだけではなく、

**「では、次に何をすればいいのか」**

まで、できるだけわかりやすく伝えます。

文章は、小学校6年生くらいまでに習う言葉を中心にします。
むずかしい言葉を使うときは、できるだけ説明をつけます。

## 大切にすること

- 使う人の利益を、いちばん大切にします。
- 不安や恐怖をあおって、サービスを使わせることはしません。
- 必要のない商品やサービスへ、むりに案内しません。
- 広告やアフィリエイトを使う場合は、それが広告だとわかるようにします。
- 広告の利益と、使う人の利益がぶつかる場合は、使う人の利益を優先します。
- 公的な制度や無料の相談窓口で十分な場合は、まずそちらを紹介します。
- 情報がわからないときは、わかったふりをしません。
- 命や安全にかかわる場合は、できるだけ早く専門の窓口につながるようにします。

## このサイトがしないこと

「こまったらドットコム」は、医師、弁護士、行政の担当者などの代わりになるものではありません。

このサイトだけですべての問題を解決することもできません。

でも、

**「どこに相談したらいいかわからない」**

という最初の壁を、少しでも低くしたいと考えています。

## しくみの考え方

制度の名前から探すのではなく、困りごとから探せるようにします。

たとえば、

> 家賃が払えない

と入力した人に、「住居確保給付金」という名前だけを見せるのではなく、使える可能性のある制度や相談先を紹介し、どこへ連絡すればよいか、何を用意すればよいかまで案内することをめざします。

住んでいる場所や年齢、家族のことなど、案内に必要な情報がある場合は、必要なことだけをたずねます。

## 最初の正解データ

まず10件の困りごとについて、人間が確認した「相談先」「使える可能性のある制度」「今日やること」「一次情報源」「確認日」を整理しています。

- [最初の10ケース](cases/README.md)
- [Issue #1](https://github.com/yo4e/comattara/issues/1)

このデータを、将来の入力 → 案内フロー、検索、UI、AI案内の評価基準にします。

## オープンなプロジェクトとして

このプロジェクトは、できるだけ多くの人が使え、改善できる形をめざします。

支援の情報は変わります。地域によっても違います。
だから、一度作って終わりではなく、まちがいを直し、新しい情報を足しながら育てていきます。
