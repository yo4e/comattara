# 最初の10ケース

Issue #1 で決めた「困りごと → 支援先 → 次にやること」の最初の正解データです。

ここにある制度や窓口は、だれでも必ず使えるとは限りません。収入、家族、年齢、住んでいる場所などで条件が変わります。

このデータでは、まず相談できる場所を先に示し、そのあとに使える可能性のある制度を示します。制度を使えるかどうかの最終判断は、役所や各窓口が行います。

**確認日：2026-09-09**

## 緊急案内ルール

通常の制度案内より、命と安全を先にします。

1. **今まさに暴力を受けている、追われている、危害が及びそう**なら、制度を探す前に **110** を案内する。
2. **急な病気や大けがなど、命にかかわるおそれがある**なら、費用の相談より先に **119** を案内する。
3. **今日食べるものがない、今夜いる場所がない**など、その日の生活がもたない場合は、「後日申請する制度」だけで終わらせず、地域の自立相談支援機関や福祉事務所へ**今日の緊急性をそのまま伝える**よう案内する。
4. 利用条件がある制度は「使える」と断定せず、**使える可能性がある**と書く。
5. 地域で窓口名や支援内容が違う場合は、全国共通の入口を先に示し、必要になってから市区町村を確認する。

## 1. 今月の家賃が払えない

**まず相談できるところ**

住んでいる地域の **自立相談支援機関**。生活や仕事、家賃などをまとめて相談できます。

**使えるかもしれない制度**

- **住居確保給付金**：収入や資産などの条件を満たすと、一定期間、家賃相当額の支給を受けられる場合があります。
- **生活保護**：収入や資産などを使っても最低限の生活ができない場合、住宅扶助を含む保護を受けられる可能性があります。

**今日やること**

1. 自立相談支援機関へ連絡し、「今月の家賃が払えない」とそのまま伝える。
2. 家賃の支払日、滞納の有無、大家や管理会社から届いた連絡があれば伝える。
3. 手元にあれば、賃貸借契約書、収入がわかるもの、預金残高がわかるものを用意する。そろっていなくても、まず相談する。

**お金はかかる？**

相談は無料。電話代や交通費などは別にかかることがあります。

## 2. 仕事を辞めて収入がない

**まず相談できるところ**

仕事を探せる状態なら、住んでいる場所を担当する **ハローワーク**。今日の生活費や家賃まで困っているなら、あわせて地域の **自立相談支援機関** に相談します。

**使えるかもしれない制度**

- **雇用保険の基本手当**：雇用保険に入っていた人が、一定の条件を満たすと受けられます。
- **求職者支援制度**：雇用保険を受けられない人などが、無料の職業訓練を受け、条件を満たせば給付金を受けられる制度です。
- 生活が成り立たない場合は、**生活困窮者自立支援制度**や**生活保護**も相談できます。

**今日やること**

1. 離職票が手元にあれば用意し、ハローワークへ相談する。まだ届いていなくても、まず手続き方法を確認する。
2. 「今日の食費がない」「家賃も払えない」など差し迫った問題があれば、ハローワークだけで終わらせず、自立相談支援機関か福祉事務所にも同じ日に相談する。

**お金はかかる？**

ハローワークや公的な相談窓口への相談は無料。電話代や交通費などは別です。

**情報源**

## 3. 食べるものがない

**まず相談できるところ**

住んでいる地域の **自立相談支援機関** または **福祉事務所**。

**使えるかもしれない制度**

- **生活保護**：最低限の生活ができない場合、食費などにあてる生活扶助を受けられる可能性があります。
- 自立相談支援機関では、地域の状況に応じて、生活全般の支援やほかの支援先へのつなぎを受けられます。

**今日やること**

1. 窓口へ「今日食べるものがなく、お金もない」と、今日の問題だとはっきり伝える。
2. 生活保護が必要だと思う場合は、福祉事務所で相談・申請する。必要な書類が全部そろっていなくても、申請できる場合があります。
3. 「数日後なら支援できる」と言われても今日の食事がない場合は、そのことをもう一度伝え、今日利用できる支援先がないか確認する。

**お金はかかる？**

相談・申請は無料。電話代や交通費などは別です。

## 4. 病院に行きたいけどお金がない

**まず相談できるところ**

命にかかわる急な症状や大けがなら、費用の心配より先に **119**。

緊急ではない場合は、住んでいる地域の **福祉事務所**、または受診したい病院の相談窓口・医療ソーシャルワーカーに、受診前に「お金がなくて受診できない」と相談します。

**使えるかもしれない制度**

- **生活保護の医療扶助**：生活保護の条件を満たす場合、医療サービスの費用が本人負担なしになる仕組みがあります。
- **無料低額診療事業**：生計が苦しい人に、無料または低額で診療を行う医療機関があります。実施していない医療機関もあります。
- **高額療養費制度**：公的医療保険に入っていて医療費が高額になる場合、自己負担を一定額までにする仕組みがあります。

**今日やること**

1. 緊急なら119。緊急でなければ、福祉事務所か病院へ先に電話する。
2. 「受診したいが、いま払えるお金がない」と伝え、使える制度や支払い方法を確認する。
3. 生活そのものも成り立たない場合は、医療費だけでなく生活保護の相談もする。

**お金はかかる？**

相談は無料。診療費は、使える制度や保険の状況によって変わります。

**情報源**

## 5. 親の介護で働けない

**まず相談できるところ**

親が住んでいる地域の **地域包括支援センター**。介護サービスや生活上の困りごとをまとめて相談できます。

今も会社に雇われている場合は、会社の人事・労務担当にも「介護が必要になった」と伝えます。

**使えるかもしれない制度**

- **介護休業**：対象となる家族の介護のために、一定期間仕事を休める制度です。
- **介護休業給付金**：雇用保険に入っていて条件を満たす場合、介護休業中に給付を受けられます。
- **介護保険サービス**：親の状態に応じて、訪問介護、通所、短期入所などを使える場合があります。

**今日やること**

1. 地域包括支援センターに「介護のため仕事を続けられない」と伝え、使える介護サービスを相談する。
2. 会社員なら、退職を決める前に会社へ介護休業や短時間勤務などを確認する。
3. 介護休業給付金については、会社またはハローワークに確認する。

**お金はかかる？**

地域包括支援センターへの相談は無料。介護サービスには原則として自己負担があります。介護休業給付金は条件を満たす人への給付です。

## 6. 家族から暴力を受けている

**まず相談できるところ**

- **今まさに危害が及んでいる、逃げる必要がある**：110
- 緊急ではないが警察へ相談したい：**#9110**
- 配偶者や交際相手からの暴力：**DV相談ナビ #8008**
- 子どもが虐待を受けている、または虐待かもしれない：**児童相談所虐待対応ダイヤル 189**

「家族からの暴力」は相手との関係で窓口が変わるため、DVだけに決めつけません。

**使えるかもしれない制度・支援**

- 警察による安全確保や相談対応
- 配偶者暴力相談支援センターによる相談・保護などの支援
- 児童相談所による子どもの安全確認・保護・相談
- 状況に応じて、自治体の生活支援や住まいの支援

**今日やること**

1. 今危険なら、制度を調べるより先に110へ連絡する。安全な場所へ移動できるなら移動する。
2. 配偶者・交際相手からの暴力なら#8008へ相談する。
3. 子どもへの虐待なら189へ相談する。189は匿名でも相談でき、通話料は無料です。

**お金はかかる？**

110、#9110への相談、189は無料です。DV相談ナビ #8008 は通話料がかかります。

## 7. 子どもの学校のお金が払えない

**まず相談できるところ**

小学生・中学生なら、通っている **学校** または住んでいる市区町村の **教育委員会**。

高校生なら、まず学校の事務室に「学費の支援制度を使いたい」と相談します。

**使えるかもしれない制度**

- **就学援助**：小中学生の保護者で、経済的に就学が難しいと認められる場合、学用品費などの援助を受けられます。認定基準は市区町村ごとに違います。
- **高等学校等就学支援金**：高校などの授業料を支援する制度です。
- **高校生等奨学給付金**：低所得世帯などを対象に、授業料以外の教育費を支援する制度があります。
- 生活保護を受けている世帯には、義務教育の学用品費などを対象とする教育扶助があります。

**今日やること**

1. 学校へ「学校に払うお金が難しい」と伝える。
2. 小中学生なら就学援助の申請先と締切を確認する。
3. 高校生なら、就学支援金や奨学給付金について学校から案内をもらう。

**お金はかかる？**

相談・申請は無料。対象になるか、いくら支援されるかは制度や地域で変わります。

- 文部科学省「就学援助制度について」

## 8. 借金の返済ができない

**まず相談できるところ**

住んでいる地域を担当する **財務局の多重債務相談窓口**。金融庁のページから地域ごとの窓口を確認できます。

法律上の整理が必要な場合は **法テラス** も相談先になります。

**使えるかもしれない制度・手続き**

- 家計の見直しや返済方法についての相談
- 弁護士・司法書士による債務整理の検討
- **法テラスの民事法律扶助**：収入や資産が一定基準以下の場合、無料法律相談や弁護士・司法書士費用の立替えを受けられる場合があります。

**今日やること**

1. 借入先、残額、毎月の返済額、支払日を、わかる範囲で紙やメモにまとめる。
2. 新しい借金で返済する前に、財務局の多重債務相談窓口へ相談する。
3. 裁判所や貸金業者から書類が届いている場合は、その書類を捨てずに保管し、相談時に伝える。

**お金はかかる？**

財務局の多重債務相談は無料。法テラスの無料法律相談は、収入や資産などの条件があります。弁護士等へ正式に依頼する費用は、手続きや制度利用によって変わります。

**情報源**

- 金融庁「多重債務者対策・貸金業法等について」  
  https://www.fsa.go.jp/policy/kashikin/
- 金融庁「多重債務についての相談窓口」  
  https://www.fsa.go.jp/soudan/
- 法テラス「無料法律相談・弁護士等費用の立替」  
  https://www.houterasu.or.jp/site/soudan-tatekae/

## 9. 住むところがなくなりそう

**まず相談できるところ**

住んでいる地域の **自立相談支援機関**。

すでに住む場所がない場合も、現在いる場所の近くの相談窓口や福祉事務所へ相談します。

**使えるかもしれない制度**

- **住居確保給付金**：条件を満たす場合、家賃相当額の支給や、家計改善のための転居費用の支援を受けられる場合があります。
- **居住支援事業**：住居がない人や不安定な住まいにいる人へ、一定期間、宿泊場所や衣食を提供する事業があります。
- **生活保護**：住む場所がない人でも申請できます。

**今日やること**

1. 退去日、家賃滞納、解約通知など、いつ住めなくなるのかを確認する。
2. 自立相談支援機関へ「○日までに住むところがなくなる」と日付を伝える。
3. 今夜の場所がない場合は、その日の宿泊場所も必要だとはっきり伝える。住居がなくても生活保護は申請できます。

**お金はかかる？**

相談・生活保護の申請は無料。支援の内容や利用条件は地域・制度によって変わります。

## 10. どこに相談したらいいのか自分でもわからない

**まず相談できるところ**

生活、お金、仕事、住まいなどがからんでいて、自分でも整理できない場合は、住んでいる地域の **自立相談支援機関** を最初の入口にします。

**使えるかもしれない制度**

相談内容を聞いたうえで、仕事、住まい、家計、生活保護、法律、医療、介護など、その人に必要な制度や専門窓口へつないでもらえる可能性があります。

**今日やること**

1. 困りごとをきれいに整理しなくてよいので、自立相談支援機関へ連絡する。
2. 最初に「何から相談したらいいかわからない」と伝える。
3. そのうえで、「今日困っていること」「今週中に困ること」があれば、それだけ先に伝える。

**お金はかかる？**

相談は無料。電話代や交通費などは別です。

**情報源**

- 厚生労働省「生活困窮者自立支援制度」

## 将来の入力 → 案内フローを評価するときの基準

この10ケースは、将来の検索・UI・AI案内を評価する基準にも使います。

最低限、次を満たしているか確認します。

- 困りごとの言い方から、制度名を知らなくても案内に入れるか。
- 最初に案内する窓口が1つに絞れているか。必要な分岐だけ追加されているか。
- 「使える制度」だけで終わらず、「今日やること」が出るか。
- 緊急時に、通常の制度案内より110・119などを先に出せるか。
- 対象条件がある制度を、利用できると断定していないか。
- 地域差がある情報を、全国一律の制度だと誤解させていないか。
- 必要以上の個人情報を入力させていないか。
- 一次情報源と確認日を追えるか。

## 更新ルール

- 制度改正、窓口変更、リンク切れがわかったら確認日と内容を更新する。
- 少なくとも定期的に一次情報を再確認する。
- 一次情報で確認できない地域独自支援は、「全国共通」として書かない。
- 民間サービスを追加する場合も、公的・無料の選択肢より上に置かない。
