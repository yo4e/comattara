# 広告・アフィリエイトの扱い

「こまったらドットコム」では、広告やアフィリエイト収益より、利用者が必要な支援へ正しくたどりつくことを優先します。

## 基本ルール

1. **先に、広告と無関係に正しい案内を決める。**
   - 公的機関、自治体、公的制度、無料相談窓口などの一次情報から、相談先と次の行動を決める。
   - アフィリエイト案件の有無を見て、案内先や順位を変えない。

2. **公的・無料の選択肢を、有料サービスより先に出す。**
   - 公的制度や無料相談で十分なときは、それを主導線にする。
   - 広告を見ないと必要な支援情報が得られない設計にしない。

3. **緊急時の主導線に広告を入れない。**
   - 110、119、189、DV相談など、命や安全に関わる案内の前後で購入や申込みを促さない。

4. **「困っているから買う・売る・借りる」へ短絡させない。**
   - 「食べるものがない」人に有料の食材宅配を主な解決策として出さない。
   - 「借金を返せない」人に、新たな金融商品や、安易な資産売却を主な解決策として出さない。
   - 「住むところがない」人に、公的支援より先に有料サービスを出さない。

5. **報酬額で順位を変えない。**
   - 高単価の案件だから上に出す、目立たせる、強い言葉で勧める、といったことはしない。

6. **広告だとわかるようにする。**
   - アフィリエイトリンクや広告を使う場合は、利用者が広告だと判断できる表示を付ける。

## 掲載してよいかの判定

アフィリエイト候補は、次の質問がすべて「はい」の場合だけ検討します。

- 報酬が0円でも、この人にこの選択肢を紹介するか？
- 公的・無料の選択肢を先に案内できているか？
- そのサービスを使わなくても、必要な支援情報は全部得られるか？
- 困っている人の焦りや弱みを利用する導線になっていないか？
- 広告であることを明示できるか？

1つでも「いいえ」なら、掲載しません。

## ケースデータとの分離

`cases/` は、相談先・制度・次の行動を評価するための**正解データ**として扱います。

アフィリエイト案件は、正解データそのものには混ぜません。将来必要になった場合は、たとえば次のように別レイヤーで管理します。

- `primary_support`: 公的・無料を中心にした主導線
- `optional_resources`: 主導線を終えたあとに役立つ補助情報
- `sponsored_resources`: 条件を満たした広告・アフィリエイト候補

UIでも `primary_support` と `sponsored_resources` を混同させません。

## 最初の10ケースについて

2026-09-09時点で確認できた参加中のA8.netプログラムには、食材宅配、買取、保険・金融、各種サービスなどがあります。

ただし、Issue #1 の最初の10ケースは、家賃、無収入、食料不足、医療費、介護、暴力、教育費、借金、住居喪失など、生活上の危機に近いケースが中心です。この段階では、既存のアフィリエイト案件を主導線へ入れる合理性は確認できませんでした。

そのため、**最初の10ケースには無理にアフィリエイト導線を追加しません。**

将来、「危機を抜けたあとの生活改善」「日常の負担軽減」などのケースが増えたときに、利用者の利益に合う案件だけを改めて検討します。
